# NEON SURVIVOR — 제작 중

프로그래밍 입문 수업에서 만드는 웹 게임입니다. 현재는 자기소개 페이지를 공개하고 있으며 게임 기능은 이후 수업에서 구현합니다.

- 저장소: https://github.com/Hwageu/my-game
- 페이지: https://hwageu.github.io/my-game/

## 게임 아이디어

NEON SURVIVOR: 네온 가상 공간에서 적을 피하며 오래 살아남는 한 화면 2D 생존 게임.
방향키로 이동하며 적을 피하고 에너지 아이템을 획득합니다. 체력이 0이 되면 게임이 종료됩니다.

### 제작 이유

HTML/CSS/JS로 만들 웹 게임으로, 조작과 규칙이 간단하면서도 재미있게 즐길 수 있을 것 같아 네온 서바이벌을 골랐습니다. 방향키로 적을 피하며 오래 살아남는 방식이라 처음 플레이하는 사람도 쉽게 이해할 수 있고, 생존 시간을 늘려 가는 도전에서 재미를 느낄 수 있을 것 같습니다. 먼저 이동과 적 회피부터 만들고, 이후 에너지 아이템과 체력 기능을 단계적으로 추가하며 완성해 보고 싶습니다.

현재 게임 로직은 구현하지 않았습니다. 게임 아이디어 카드에는 정적인 Canvas 콘셉트 미리보기가 표시됩니다.

## RELEASE 1 — 2026-10-08

기존 RELEASE 기록이 없어 첫 성공한 개발 작업을 RELEASE 1로 기록합니다.

- 변경 파일: `index.html`, `style.css`, `script.js`, 이 `README.md`.
- NEON SURVIVOR: 네온 경기장, 생존자, 적과 에너지 아이템.
- VOID DODGER: 성운, 행성, 운석과 우주선.
- CYBER ESCAPE: 사이버 도시 통로, 데이터 조각, 인물과 출구.
- 세 미리보기는 접힌 카드에서도 보이며, 게임 설명과 기존 펼침 기능을 유지합니다. 데스크톱 가로 배치와 모바일 세로 배치, 중앙 기준 cover 크롭, Canvas의 이미지 역할·대체 설명과 폴백 텍스트를 적용했습니다.
- 출처·권리: 세 미리보기는 이 프로젝트를 위해 `script.js`의 Canvas 2D API로 직접 제작한 독자적 도형·그라디언트 그림입니다. 이전 대화의 검색 결과 이미지, 외부 이미지·에셋·라이브러리를 사용하지 않았으므로 제3자 이미지 라이선스는 적용되지 않습니다. 별도 공개 라이선스는 부여하지 않았습니다. 기존 좋아하는 게임 이미지의 출처·권리 안내는 유지했습니다.
- 검증: 설치된 Microsoft Edge에서 1440, 768, 390, 320px 뷰포트 확인. 세 Canvas 렌더링, 기존 이미지 로딩, 가로 넘침 없음, 모든 카드 펼침/접힘, 라이트/다크 테마 전환 통과. 데스크톱·모바일 스크린샷 시각 확인. 페이지 및 콘솔 오류 0건.
- 기존 콘텐츠·날짜·메뉴·테마·스크롤 기능을 유지했습니다. 회고는 작성하거나 수정하지 않았습니다. 배포·커밋·푸시는 수행하지 않았습니다.
