# NEON SURVIVOR — 제작 중

프로그래밍 입문 수업에서 만드는 웹 게임입니다. 현재는 requestAnimationFrame 게임 루프에서 드론 3대가 움직이는 4주차 실습 단계입니다. 플레이어 조작과 충돌·점수 계산은 이후 구현합니다.

- 페이지: https://hwageu.github.io/my-game/

## 게임 아이디어

NEON SURVIVOR: 넓은 네온 공간을 이동하면서 적을 피하고 오래 살아남는 2D 생존 게임.
방향키로 이동하며 적을 피하고 에너지 아이템을 획득합니다. 체력이 0이 되면 게임이 종료됩니다.

### 제작 이유

HTML/CSS/JS로 만들 웹 게임으로, 조작과 규칙이 간단하면서도 재미있게 즐길 수 있을 것 같아 네온 서바이벌을 골랐습니다. 방향키로 적을 피하며 오래 살아남는 방식이라 처음 플레이하는 사람도 쉽게 이해할 수 있고, 생존 시간을 늘려 가는 도전에서 재미를 느낄 수 있을 것 같습니다. 먼저 이동과 적 회피부터 만들고, 이후 에너지 아이템과 체력 기능을 단계적으로 추가하며 완성해 보고 싶습니다.

800×600은 전체 맵이 아닌 화면에 보이는 범위입니다. 향후 플레이어를 따라가는 카메라와 이어지는 지형을 구현합니다. 현재는 넓은 맵의 일부를 배경으로 드론 이동을 연습합니다. 플레이어 이동·카메라 추적·지형 연결은 아직 구현하지 않았습니다. Canvas에 플레이어, 적 3마리, 에너지 코어와 초기 상태를 표시합니다. 세부 규칙은 [기획서](기획서.md)에 정리했습니다.

- `기획서.md`: 게임 규칙과 화면 배치, 주차별 구현 계획

## 배경 이미지

- `assets/floor-tile.jpg`: 이 프로젝트를 위해 OpenAI 이미지 생성 도구로 제작한 반복용 SF 금속 바닥입니다. 외부 게임의 이미지나 스크린샷을 사용하지 않았습니다. 원본을 웹용 JPEG로 인코딩했습니다.
- `Image.onload`에서 이미지를 불러온 뒤 반사 타일을 만들고, Canvas의 `createPattern(..., "repeat")`으로 가로·세로 반복합니다. 반사 배치로 타일 양쪽 경계를 연결합니다.
- 3주차에는 반복 배경을 정적으로 표시합니다. 실제 스크롤과 월드 좌표·카메라 추적은 이후 주차에 구현합니다.

## 캐릭터 이미지

- `assets/survivor.png`: 민트색 바이저와 금속 장갑복을 착용한 생존자.
- `assets/drone.png`: 분홍색 렌즈와 기계 날개를 가진 적 드론.
- 두 이미지는 이 프로젝트를 위해 OpenAI 이미지 생성 도구로 제작한 투명 PNG이며, 외부 게임의 캐릭터 이미지를 사용하지 않았습니다. Canvas에서 원본의 투명 여백을 제외해 그리며, 바닥 그림자는 코드로 따로 표시합니다.
- 배경·생존자·드론·코어 이미지의 로딩이 모두 끝난 뒤 첫 화면을 그립니다. 이동·방향 전환 애니메이션은 아직 구현하지 않았습니다.

## 방향별 모션 준비

- `assets/survivor-directions.png`: 동일한 생존자의 3열×4행 방향별 스프라이트 시트입니다. OpenAI 이미지 생성 도구로 제작했습니다.
- 위에서부터 아래·왼쪽·오른쪽·위 방향이며, 각 행은 대기·걷기 A·걷기 B 순서입니다. 투명 PNG로 배경과 분리되어 있습니다.
- 현재 첫 화면에는 `survivor.png`의 정지 자세를 사용합니다. 방향 시트 재생과 입력 연결은 이후 주차에 구현하며, 그때 프레임별 기준점과 보행 연결을 검증·보정합니다.
- 드론은 강체 스프라이트의 회전과 부유 효과로 방향·움직임을 표현할 계획입니다. 현재는 정지 이미지입니다.

## 레트로 화면과 모션 자산

- 월드를 400×300 보조 Canvas에 그린 후 보간 없이 두 배 확대합니다. 배경과 캐릭터·아이템의 도트 배율을 통일하고, HUD 글자는 800×600 해상도에서 따로 표시합니다.
- CSS로 무광 게임기 케이스, 유리 화면 테두리와 약한 주사선을 표현합니다. 플래시나 깜빡임은 없습니다.
- `assets/drone-directions.png`: 아래·왼쪽·오른쪽·위 방향 순서의 4행, 대기·추진기 펄스 A·B의 3열 시트입니다. 프레임 중심과 연결감은 재생 구현 시 검증합니다.
- `assets/energy-core.png`: 2×2 회전·부유 프레임입니다. 현재는 왼쪽 위의 첫 칸을 표시합니다.
- 두 시트는 OpenAI 이미지 생성 도구로 이 프로젝트를 위해 제작했습니다. 3주차에는 모션 자산만 준비했습니다. 4주차에는 드론 이동과 추진기 모션을 연결했으며, 생존자 보행과 코어 회전은 아직 연결하지 않았습니다.
