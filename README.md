## 게임 아이디어

NEON SURVIVOR: 네온 가상 공간에서 적을 피하며 오래 살아남는 한 화면 2D 생존 게임.
방향키로 이동하며 적을 피하고 에너지 아이템을 획득합니다. 체력이 0이 되면 게임이 종료됩니다.

### 제작 이유

HTML/CSS/JS로 만들 웹 게임으로, 조작과 규칙이 간단하면서도 재미있게 즐길 수 있을 것 같아 네온 서바이벌을 골랐습니다. 방향키로 적을 피하며 오래 살아남는 방식이라 처음 플레이하는 사람도 쉽게 이해할 수 있고, 생존 시간을 늘려 가는 도전에서 재미를 느낄 수 있을 것 같습니다. 먼저 이동과 적 회피부터 만들고, 이후 에너지 아이템과 체력 기능을 단계적으로 추가하며 완성해 보고 싶습니다.

현재 게임 로직은 구현하지 않았습니다. Canvas에 플레이어, 적 3마리, 에너지 코어와 초기 상태를 표시합니다. 세부 규칙은 [기획서](기획서.md)에 정리했습니다.

## 파일과 실행

- `index.html`: 800×600 Canvas
- `style.css`: 어두운 배경과 Canvas 중앙 배치
- `script.js`: 정적인 네온 서바이벌 첫 화면 그리기
- `회고.md`: 1주차와 2주차 활동 기록

VS Code에서 이 `my-game` 폴더를 열고 Live Server로 `index.html`을 실행합니다.
HTML은 같은 폴더의 `style.css`와 `script.js`를 상대 경로로 연결합니다. 빌드 도구나 외부 라이브러리는 사용하지 않습니다.
