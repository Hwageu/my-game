# NEON SURVIVOR

넓은 네온 공간을 이동하면서 적을 피하고 에너지 코어를 모아 오래 살아남는 2D 생존 게임입니다.
7주차 디버깅 실습과 코드 정리까지 진행했습니다. 숨은 버그 3개를 찾아 수정하고, 피격 반응을 보강했습니다. D키로 좌표·드론 수·게임 상태·점수와 판정 영역을 함께 확인할 수 있습니다. 기본 화면에서는 디버그 표시를 숨깁니다.

### 제작 이유

HTML/CSS/JS로 만들 웹 게임으로, 조작과 규칙이 간단하면서도 재미있게 즐길 수 있을 것 같아 네온 서바이벌을 골랐습니다. 방향키로 적을 피하며 오래 살아남는 방식이라 처음 플레이하는 사람도 쉽게 이해할 수 있고, 생존 시간을 늘려 가는 도전에서 재미를 느낄 수 있을 것 같습니다. 먼저 이동과 적 회피부터 만들고, 이후 에너지 아이템과 체력 기능을 단계적으로 추가하며 완성해 보고 싶습니다.

## 조작과 현재 기능

- 방향키로 상하좌우·대각선 이동합니다. 플레이어 속도는 2, 드론 기준 속도는 1.15입니다.
- 눌린 키를 keys에 기록하고 게임 루프에서 이동을 계산합니다. 키를 떼거나 창·탭을 벗어나면 입력을 해제합니다.
- 카메라가 플레이어를 따라가고 배경은 가로·세로로 반복됩니다. 800×600은 맵 전체가 아닌 화면 표시 범위입니다.
- 이동 방향에 맞는 걷기 모션을 표시하며, 손을 떼면 해당 방향의 대기 자세를 유지합니다. 좌우 보행 전환 간격은 320ms입니다.
- 드론은 4대로 시작하고 실제 생존 시간 10초마다 1대씩 늘어나 최대 12대가 됩니다. 화면 밖에서 진입하며 멀어진 드론은 지연 후 다시 생성합니다. 재시작하면 4대로 돌아갑니다.
- 코어는 640×640 구역마다 2개를 랜덤 배치합니다. 구역을 유지하는 동안 위치가 바뀌지 않으며 캐시는 최대 128개로 제한합니다.
- 코어를 획득하면 10점이 오르고, 5개마다 체력 1을 회복합니다. 최대 체력은 3입니다.
- 드론과 충돌하면 체력이 1 줄고 1초 동안 무적입니다. 체력이 0이면 게임이 종료됩니다.
- 게임 오버 화면에서 R키를 누르면 점수·체력·시간·위치·드론과 코어가 초기화됩니다. 생존 시간은 실제 경과 시간으로 표시합니다.
- 드론은 실제 생존 시간 20초마다 초기 속도의 10%씩 빨라집니다. 최대 1.8배이며 새로 등장하는 드론도 같은 배율을 적용합니다. R키로 재시작하면 1배로 돌아갑니다.
- 기본 설정이 쉽다는 플레이 의견을 반영해 드론 수를 3→4, 기준 속도를 1→1.15로 올렸습니다. 판정 테두리는 꺼 두었습니다.

- 피격 순간 퍼지는 테두리와 HIT -1 표시, 1초 무적 보호막을 표시합니다.
- D키로 디버그 정보와 판정 영역을 함께 켜고 끕니다.

- M키로 효과음 전체를 끄거나 켭니다. 음소거 상태는 재시작해도 유지되며 화면 오른쪽 아래에 표시합니다.
- 코어 획득·피격·게임 오버 효과음은 직접 합성한 짧은 WAV 파일입니다.

## 파일과 실행

VS Code에서 my-game 폴더를 열고 Live Server로 index.html을 실행합니다.
순수 HTML/CSS/JS를 사용하며 외부 라이브러리나 빌드 도구는 없습니다. 코드와 이미지는 상대 경로로 연결합니다.

## 그래픽과 이미지 출처

모든 이미지 자산은 이 프로젝트를 위해 OpenAI 이미지 생성 도구로 제작했습니다. 외부 게임의 이미지·스크린샷을 사용하지 않았습니다.

| 이미지 | 사용 용도 |
|---|---|
| assets/floor-tile.jpg | 가로·세로 반복 금속 바닥. 반사 타일로 경계를 연결 |
| assets/survivor-directions.png | 방향별 대기 자세. 실제 프레임 경계로 잘라 표시 |
| assets/survivor-walk.png | 상하 보행 프레임 |
| assets/survivor-sidewalk.png | 좌우 전신 보행. 오른쪽은 전신을 함께 반사 |
| assets/drone-directions.png | 드론 방향별 추진기 모션 |
| assets/energy-core.png | 코어의 첫 프레임. 회전 재생은 아직 미구현 |

이미지 로딩이 모두 끝난 뒤 게임 루프를 시작합니다. 월드는 400×300 보조 Canvas에서 그린 후 보간 없이 두 배 확대하며, HUD는 원래 해상도에서 별도로 표시합니다. 프레임마다 발 기준점을 통일하고, 다리를 도형으로 덧그리지 않습니다.
