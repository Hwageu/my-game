## 게임 아이디어

VOID DODGER: 방향키로 우주선을 움직이며 운석을 피하는 한 화면 2D 게임.
사용자의 요청에 따라 기존 세 후보 중 구현 범위가 가장 작은 아이디어를 선택했습니다.
이동과 운석 회피부터 시작하고 점수와 체력은 이후 수업에서 추가할 수 있어, 여러 적의 행동이나 데이터 수집·탈출을 동시에 구현하는 후보보다 단계적으로 만들기 쉽습니다.
현재 게임 로직과 Canvas는 구현하지 않았습니다.

## 진행 상황

- [x] 1주차: 자기소개 페이지
- [ ] 2주차: GitHub Pages 배포 검증
- [ ] 2주차: 학생 본인의 회고 작성
- [ ] 3주차: 게임 화면 그리기

## 파일과 실행

- `index.html`: 자기소개와 게임 아이디어
- `style.css`: 화면 스타일과 반응형 배치
- `script.js`: 테마 전환, 날짜, 스크롤 효과
- `회고.md`: 기존 1주차 회고와 2주차 작성 양식

VS Code에서 이 `my-game` 폴더를 열고 Live Server로 `index.html`을 실행합니다.
HTML은 같은 폴더의 `style.css`와 `script.js`를 상대 경로로 연결합니다. 빌드 도구나 외부 라이브러리는 사용하지 않습니다.

## 수정과 배포

변경 → 로컬 확인 → 의미 있는 메시지로 커밋 → main 푸시 → 배포 주소 확인.
GitHub Pages 설정: Deploy from a branch / main / (root).

## 제출 전 확인

로그인 없는 접근, 화면과 테마 전환, 콘솔 오류, 상대 경로와 파일 대소문자를 확인합니다.
회고의 프롬프트·문제 해결·코드 설명은 학생이 직접 작성합니다.
