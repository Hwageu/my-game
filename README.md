# NEON SURVIVOR

[게임 플레이](https://hwageu.github.io/my-game/) · [GitHub 저장소](https://github.com/Hwageu/my-game)

넓은 네온 공간에서 드론을 피하고 에너지 코어를 모으는 2D 생존 게임입니다. 간단한 조작으로 오래 버티며 기록에 도전할 수 있을 것 같아 이 게임을 골랐습니다.

- 학번 / 이름: 202370036 / 서준영

![게임 시작 화면](screenshot.png)

## 조작법

| 입력 | 동작 |
|---|---|
| 시작 화면에서 키 또는 클릭 | 게임 시작 |
| 방향키 | 상하좌우·대각선 이동 |
| R | 게임 오버 후 재시작 |
| M | 배경음악·효과음 전체 음소거 전환 |
| D | 디버그 정보와 판정 영역 전환 |
| L | 시작·게임 오버 화면에서 온라인 TOP 10 |
| N | 게임 오버 후 닉네임으로 기록 등록 |

M·L은 시작 대신 해당 기능을 실행합니다. 디버그는 기본으로 꺼져 있습니다.

## 규칙

- 플레이 중에는 20초 길이의 레트로 신스 음악을 음량 0.65로 반복합니다. 시작 전에는 재생하지 않고, 게임 오버 때 정지합니다. M키로 음악과 효과음을 함께 끕니다.

- 체력 3, 코어 1개당 10점, 5개마다 체력 1 회복(최대 3).
- 충돌 시 체력 1 감소와 1초 무적, 체력 0이면 종료.
- 무한 맵과 카메라를 사용하며 800×600은 표시 범위입니다.
- 드론은 4대부터 10초마다 1대 추가, 최대 12대.
- 20초마다 초기 속도의 10% 증가, 최대 1.8배.
- HUNTER 한 대는 12초 후 진입해 추적합니다. 최고 속도 1.71로 플레이어 속도 2보다 느립니다.
- R키로 점수·체력·위치·시간·난이도·적·코어를 초기화합니다. 최고 점수와 음소거는 유지합니다.
- 코어는 구역별 랜덤 배치이며 최대 128구역을 보관합니다. 정리된 구역에 다시 오면 위치가 바뀔 수 있습니다.
- 게임 오버 문구는 messages.json에서 고르며 실패하면 기본 문구를 씁니다.

## 모바일

PC에서 방향키로 플레이해 주세요. 휴대폰에서는 화면·시작·소리를 확인할 수 있지만 터치 이동은 지원하지 않습니다. 화면 크기만 줄이며 Canvas 좌표 크기는 유지합니다.

## 온라인 랭킹

Supabase REST API로 닉네임과 점수를 등록하고 상위 10개를 표시합니다. N키를 눌렀을 때만 등록하며 한 판의 중복 제출을 막습니다. 닉네임은 1~8자, 점수는 정수 0~100만입니다. 실명·학번·연락처를 입력하지 마세요.

RLS와 SQL 권한으로 읽기·등록만 허용하고 수정·삭제를 차단합니다. 등록 시각은 서버가 기록합니다. 코드의 sb_publishable_ 키는 공개용이며 비밀 키·DB 비밀번호는 넣지 않았습니다. 서버 실패 시에도 게임과 로컬 최고 점수는 동작합니다. 브라우저가 보내는 점수를 완전히 검증할 수는 없습니다. 검증용 0점은 서버 테스트 기록이며 사람의 플레이 점수가 아닙니다.

[보안점검.md](보안점검.md)에 실제 검증 결과를 기록했습니다.

## 개발 환경과 실행

Windows, VS Code, Live Server, Git·GitHub, GitHub Pages를 사용합니다. 폴더를 VS Code에서 열고 index.html을 Live Server로 실행합니다. 본 게임은 순수 HTML/CSS/JS 3파일이며 외부 게임 라이브러리나 빌드 도구를 쓰지 않습니다. 파일 직접 열기에서는 JSON 대신 기본 문구를 사용합니다. 네트워크가 끊겨도 이미 불러온 게임은 계속됩니다.

### 게임 선택과 일시정지

오락기 형태의 NEON ARCADE 메뉴에서 NEON SURVIVOR를 선택합니다. 다른 두 게임은 준비 중이며 실행되지 않습니다. 게임 중 P 또는 ESC, 화면 아래 일시정지 버튼으로 멈출 수 있습니다. 재개하면 3·2·1 뒤 이어집니다. 멈춘 시간과 카운트다운은 생존 시간·난이도·무적 시간에서 제외하며 배경음악도 멈춥니다. 탭이나 창을 벗어나면 자동으로 일시정지합니다. 게임 선택 메뉴로 돌아갔다가 현재 판을 이어갈 수도 있습니다.

메뉴에서는 ↑·↓로 선택하고 Enter·Space 또는 조작대 START 버튼으로 실행합니다. 조이스틱 위·아래 버튼이나 게임 이름 클릭으로도 선택할 수 있습니다. 준비 중인 게임을 선택해 실행하면 안내 문구를 표시합니다. 캐비닛 구조는 첨부된 오락기 사진과 [Neo Geo MVS 자료](https://www.arcade-museum.com/Videogame/neo-geo-mvs)를 참고했으며, 외부 로고·게임 그림은 사용하지 않았습니다.

메뉴와 플레이 화면은 동일한 캐비닛·CRT 테두리를 공유합니다. START 버튼은 플레이 중 일시정지, 멈춘 상태에서는 3초 뒤 재개, 게임 오버에서는 재시작으로 동작합니다. BGM 기본 음량은 0.65이며 M키로 효과음과 함께 음소거합니다.

조작대 조이스틱은 위에서 본 원형 받침대와 손잡이로 표현하며 금속 축은 표시하지 않습니다. 방향키 입력에 따라 손잡이가 해당 방향으로 움직입니다. 대각선을 지원하며 키 해제·창 이탈·일시정지 시 중앙으로 돌아옵니다. 받침대는 고정되어 있습니다.

## VOID BREACH — 메뉴 2번

Three.js 기반의 독립적인 3D FPS 첫 플레이 버전입니다. 전력 노드 3개를 E키로 복구하고 북동쪽 탈출구에 도달합니다. WASD 이동, Shift 달리기, 마우스 조준·좌클릭 사격, R 장전, 1/2/3 무기 전환, Esc 일시정지입니다. 미니맵과 다음 목표의 방향·거리를 표시합니다. 마우스 잠금을 사용할 수 없는 환경은 시작 화면의 대체 모드에서 우클릭 드래그로 시점을 조작합니다.

게임 코드는 fps/에 분리했습니다. vendor/에는 Three.js 0.180.0과 MIT 라이선스를 보관합니다. 시설·무기·로봇 모델과 표면 무늬 및 효과음은 코드로 제작했습니다. 첫 버전의 모델은 단순한 형태이며 이후 시각 품질을 다듬을 예정입니다. 기존 네온 서바이벌에도 비율을 유지하는 전체화면 버튼을 제공합니다.
